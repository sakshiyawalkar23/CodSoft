# To-Do List Manager

A GUI-based To-Do List application developed using Python and Tkinter. This project helps users manage daily tasks in a simple and efficient way using an interactive desktop interface.

## Features

- Add new tasks
- Update selected tasks using popup window
- Mark tasks as completed
- Delete tasks
- Scrollable task list
- Clean dark-themed interface
- User-friendly alerts and warnings

## Technologies Used

- Python
- Tkinter

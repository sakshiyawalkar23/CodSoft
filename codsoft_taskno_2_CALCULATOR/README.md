# Neo Calculator

Neo Calculator is a modern GUI-based calculator developed using Python and Tkinter. It performs standard arithmetic calculations with an attractive dark-themed interface and includes extra utility functions such as square root, percentage, square, and history tracking.

## Features

- Basic arithmetic operations (+, -, ×, ÷)
- Decimal calculations
- Percentage calculation
- Square root function
- Square (x²) function
- Backspace and clear options
- Calculation history window
- Modern responsive dark UI
- Error handling for invalid expressions

## Technologies Used

- Python
- Tkinter
- Math Module

# PASSFORGE Password Generator

PASSFORGE is a modern GUI-based password generator developed using Python and Tkinter. It helps users create secure and customizable passwords instantly with strength analysis and clipboard support.

## Features

- Generate strong random passwords
- Adjustable password length (4 to 64 characters)
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include symbols
- Remove ambiguous characters (O, 0, l, I, 1)
- Password strength meter
- Copy password to clipboard
- Stylish cyber-themed dark interface

## Technologies Used

- Python
- Tkinter
- Random Module
- String Module
